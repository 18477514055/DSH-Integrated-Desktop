# DSH 集成桌面端 0.2.1

把官方 DeepSeek Harness 内核装进原生 Electron 外壳。**外壳不修改内核的任何文件**，
内核由外部独立安装与升级 —— 升级内核不需要动外壳。

> **这一版相对 0.2.0 的运行时增量只有一处：多会话插件的加入。**
> 0.2.0 的下一批提交里，其余都是文档与构建工具（`scripts/` 不进 exe），
> 只有 `plugin/**/*` 会打进安装包 —— 所以 0.2.1 的安装包里多出来的就是下面这个东西。

## 这一版做了什么

### 1. 新增：多会话插件（`plugin/dsh-multi-session`）

主输入框右侧、发送键旁边多了一个 **「多会话」** 按钮。点开是一个大弹窗，
里面是 **N 个和主输入框功能对等** 的输入行（除了「发送」以外全都有）：

- `/` 命令菜单、`@` 文件引用、模型选择、附件上传 —— 与主输入框一致；
- 默认 1 行，点「新增会话」加行，可以一次写好 N 条互不相干的提示词；
- **右下角一个「一键发送」** —— 按下去会**并行创建 N 个独立会话**，各发各的。

设计上的取舍：**不在你点「发送」之前创建任何会话**。官方 `sessions` 命名空间
没有删除接口，先建后撤做不到 —— 所以中途关掉弹窗不会在你侧边栏里留下 N 个空会话。

### 2. 弹窗里的模型选择器：搜索框 + 来源筛选胶囊

弹窗里每个输入行都能选模型，那个菜单里加了搜索框与来源筛选：

- 按模型名 / 提供方 / 描述搜索；
- 提供方胶囊（例如 `全部` / `deepseek-official` / `workbuddy` / `workbuddy-global`），
  再点一次取消；只在提供方多于一个时才出现；
- 筛选语义与外壳自己那个模型搜索框**逐条对齐**（命中提供方名则整组显示、胶囊数字是该来源的总数、
  空结果显示「没有匹配的模型（共 N 个）」+「清空搜索与筛选」）。

### 3. 修掉两个会丢用户东西的 bug

两个都是在真跑里暴露的，症状都比听起来严重：

| bug | 症状 | 根因 |
|---|---|---|
| **Esc 会关掉整个弹窗** | 在搜索框里按 Esc 想清掉关键词，结果弹窗整个消失、**N 条已写好的提示词一起没了** | 官方 `primitives.Modal` 自己在 `document` 上挂了 Escape→`onClose`，冒泡上去就触发了 |
| **发送键永久卡在「发送中…」** | 界面永远停在发送中，**而宿主其实早已受理并落盘** | 官方的 `conversation.sendSession` 在带附件时会 await 乐观回显的"退休"，而刚建的会话没有被跟随 ⇒ promise 永不结算 |

两条的修法都记在 `plugin/dsh-multi-session/README.md` 的「真实坑」表里，
并在 `AGENTS.md` 里升级成了**插件开发的硬规矩**（不许用 `sendSession` 提交带附件、
不许用官方 `Modal` 当最外层），避免下次重踩。

### 4. 插件清单页（**尚未实现**）

已按你的要求记进 `AGENTS.md` §2：以后做一个「来自我们这个包的插件」列表，
在主界面里能看见本包带了哪些插件。落点已勘察（官方有 `settings.plugins.tab` 与
`sidebar.footer.action` 两个槽位），**这一版还没有它**。

## ⚠️ 插件需要单独装一次（重要）

安装包**带了**这个插件（在 `plugin/dsh-multi-session/`），但**不会自动装进你的 DSH 环境** ——
装插件要写你的 DSH_HOME 并**重启客户端**才生效，这两件事都不适合在安装器里偷偷做。

装法（在项目目录里）：

```powershell
npm run plugin:status     # 先看装了没有
npm run plugin:install    # 装（自动备份 profiles/web/package.json）
npm run plugin:check      # 真跑一遍验收
npm run plugin:revert     # 不想要了就退回
```

装完**必须重启一次客户端**（托盘右键 → 退出 → 重新打开）：
宿主在启动时会把客户端 bundle 快照下来，**页面刷新换不掉它**。

## 验证方式

都是**真跑真看**，不是"文件存在"：

```
npm run plugin:check     # 搭临时环境真启动客户端，真点按钮、真发消息、真去磁盘上找提示词与附件字节
npm run release:check    # 分发暂存区逐文件机械审计（路径黑名单 + 扩展名白名单 + 内容密钥模式）
```

`plugin:check` 本轮**连跑 4 次全过**（发送耗时 1.5–3.3 秒），
验的是"两个会话都真的建出来、两段提示词与附件字节都真的落了盘"，**不看插件自己的结果文案**。

0.2.0 的界面验证依旧有效，回归可直接跑：
`node scripts/ui-check.js loading|inject|reuse|probe`。

## 安装须知

1. **先退出正在运行的旧版本**（托盘右键 → 退出；点右上角 X 只是最小化到托盘）。
   本应用是单实例的，旧版还开着的时候启动新版会**直接退出并聚焦旧窗口**，看起来像"双击没反应"。
2. 装完如果桌面图标还是旧的，那是 **Windows 图标缓存**，不是没装上：
   `ie4uinit.exe -show`，或重启一次资源管理器。
3. 需要本机已安装官方内核：`npm i -g @deepseek-ai/dsh`。
4. 想用多会话弹窗，按上面「插件需要单独装一次」做，并重启客户端。
