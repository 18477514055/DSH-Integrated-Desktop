# DSH 集成桌面端 0.2.3

把官方 DeepSeek Harness 内核装进原生 Electron 外壳。**外壳不修改内核的任何文件**，
内核由外部独立安装与升级 —— 升级内核不需要动外壳。

> **这一版加了一个页面切换器**：同一个窗口里就能在
> **本机 DSH / DeepSeek 网页版 / DeepSeek 开放平台** 之间来回切。

## 这一版做了什么

### 三页切换

窗口**右侧边缘**有一条细把手（默认 20px，悬停展开），点一下弹出三页清单，
点哪一页就切到哪一页。当前所在的那一页会打 ✓。

| 页面 | 是什么 |
|---|---|
| **本机 DSH** | 就是这个客户端本身（本机内核的官方界面） |
| **DeepSeek 网页版** | <https://chat.deepseek.com/> |
| **DeepSeek 开放平台** | <https://platform.deepseek.com/> |

**三个入口，随手哪个都行**（把手是主入口，另外两个是保险 —— 万一某个页面出问题，
不至于出不来）：

- 右侧边缘的把手（和手机端"点屏幕外侧"一个手感）；
- **托盘图标右键 → 页面**（带当前页勾选）；
- 快捷键 **Ctrl+1 / Ctrl+2 / Ctrl+3**。

### 几个刻意的取舍

- **切走之后本机页面不会停**：网站是以**一层独立视图**盖在窗口上的，
  本机界面还在下面活着 —— 内核不断线、会话照常跑（长回答不会因为你看了一眼网页就被打断）。
- **切回来不重载**：网站页面只是被隐藏，**不销毁** ⇒ 来回切**不丢滚动位置、不丢登录态**。
- **网站页面里也有这个把手**：否则进去之后就没有出口了（只能靠托盘）。
- **登录态存在应用自己的数据目录里**：登录一次就记住，下次打开还在。

### 为什么这件事必须进外壳，而不是做成插件

按项目一直的规矩（"能放进来就放进来，放不进来就放插件"）先试了插件路线 —— **走不通**：
插件跑在官方前端的 React 树里，只有**网页**的能力，而"把 chat.deepseek.com 装进同一个窗口"
需要 Electron 的窗口/视图层（`WebContentsView`）。

也**不能用 `<iframe>`**：DeepSeek 两个站点都带 `X-Frame-Options` / `frame-ancestors`，
内嵌会被浏览器直接拒绝；而且 iframe 里的登录态与主页面互相割裂。

### 安全边界

切换通道（`dsh:page:switch`）**允许官方 UI 与两个外部站点调用** ——
因为把手是注入到那些页面里的。边界靠"**取值写死**"而不是靠来源：
合法取值只有 `dsh` / `chat` / `platform` 三个 id，别的一律拒（`ui-check pages` 里专门
用 `evil` 与 `../../etc` 验过）。⇒ 即使第三方站点的脚本也拿到这个通道，
它最多只能在这三页之间切，**不能执行命令、不能读写文件**。

## 实现时踩到的一个坑（值得记）

给注入的把手挂事件时，第一版是在**把手自身上**用**捕获阶段** `stopPropagation()`
来防止宿主页面（React）看到点击 —— 结果**同一元素上冒泡阶段的监听器全部不执行**：
元素在、监听器也在，`el.click()` 却什么都不发生（现场新挂一个监听器测，
`extraListenerFired: 0`）。

原因是 Chromium 把目标节点的捕获监听器放在**捕获趟**里跑，一旦在那里 stop 掉，
后面的**目标趟**就被整个跳过。⇒ 正确做法是挂在**组件根节点**、用**冒泡**阶段拦截。

## 验证方式（真跑，不看自述）

```
node scripts/ui-check.js pages      # ★ 本版新增：三页切换的真跑验收（15 项断言）
node scripts/ui-check.js loading    # 加载页 + 诊断抽屉（回归）
node scripts/ui-check.js inject     # 模型搜索框注入（回归）
```

`ui-check pages` 会自己起一个临时内核，然后**真的**做这些事：

- 把手真的画进了 DOM、面板默认收起、三页 id 与中文标签正确、当前页打了 ✓；
- **真的点一下把手**，面板真的展开（看 `display`，不看代码）；
- **真的调 `switchPage('platform')`**，然后**再读一次主进程状态**确认 `active` 变了
  （不是只有按钮变了）；
- **非法 id 真的被拒**（`evil` / `../../etc`）；
- 切回本机，状态确实回到 `dsh`；
- **站点页面里也真的注入了把手**（这一段要联网，连不上会明确标 SKIP，不当成通过）。

## 安装须知

1. **先退出正在运行的旧版本**（托盘右键 → 退出；点右上角 X 只是最小化到托盘）。
   本应用是单实例的，旧版还开着的时候启动新版会**直接退出并聚焦旧窗口**，看起来像"双击没反应"。
2. 装完如果桌面图标还是旧的，那是 **Windows 图标缓存**，不是没装上：
   `ie4uinit.exe -show`，或重启一次资源管理器。
3. **需要本机已安装官方内核**：`npm i -g @deepseek-ai/dsh`
   （本版**没有**把内核打进去 —— 那样安装包要从 89 MB 涨到 250 MB 上下，
   而需要这个客户端的人本来就有 Node）。
4. **插件不用单独装** —— 打开客户端就有（0.2.2 起内置）。
