# 0.2.19 —— 把最后两条注入也插件化（`model-search` / `sidebar-open`）

> **这一版要解决的问题**（用户 2026-09-29 原话）：
> 「把剩下没有进行插件化的也插件化完毕。**同时推送到仓库上，让我能够在官方端上复刻集成版。**」
>
> 背景：2026-09-29 社区版已卸载、**官方桌面端 `DeepSeek Harness 0.2.0-rc.2` 已装**
> （它把 `%USERPROFILE%\.dsh` 当自己的家）。本机集成版（DSH Integrated）仍是日常入口。
> **能让集成版的价值跟着内核走的东西，只有插件。** 所以 0.2.19 把还留在外壳里的两条
> 页面注入搬成了独立客户端插件。

## 一、两条注入 → 两个插件

| 原注入（跟外壳走） | 新插件（跟内核走） | 说明 |
|---|---|---|
| `src/inject/model-search.js`（22 KB） | **`plugin/dsh-int-model-search`** v0.1.0 | 官方「选择模型」下拉的**搜索框 + 提供方筛选胶囊** |
| `src/inject/sidebar-open.js`（21 KB） | **`plugin/dsh-int-sidebar-open`** v0.1.0 | 侧栏文件树的**用默认应用打开 / 在资源管理器中显示**（右键菜单含复制路径） |

**第三个注入 `page-switch.js`（三页切换）刻意留在外壳** —— 它要 Electron 的 `WebContentsView`
（把 chat.deepseek.com 装进同一个窗口），插件跑在网页里，拿不到视图层，这是**能力边界**不是懒。

### 移植方式：机械移植，注入体逐字不变

`lib/client.js` **由脚本生成**，不是手抄：

```powershell
npm run port:gen          # 重新生成两个 client.js
npm run port:gen:check    # 只校对（退出码 2 = 与注入脚本不一致，必须重跑）
```

- 生成器：`scripts/port-inject-to-plugin.js`。它读 `src/inject/*.js`，把**整段注入体原样**
  包进插件工厂，只在**显式列出的锚点**上替换；锚点匹配失败**立刻报错退出**（绝不静默产出坏文件）。
- 为什么这样做：那 400 多行 DOM 逻辑过了 4 轮真跑验收（`ui-check inject` / `ui-check files`），
  手抄必然引入无声差异。
- 包装层只做两件事（**都不改注入体**）：
  ① **body 守卫** —— 插件版的 `apply()` 可能在 `document.body` 出现之前跑，而注入体里
     `observe(document.body, …)` 传 null 会抛；body 不在就等 `DOMContentLoaded`。
  ② **桥** —— 侧栏那条把官方 `session.openWorkspacePath` 包装成注入体认得的
     `openWorkspaceFile(path, action)`（**只改了注入体一行**：`var shell = window.dshShell;` → `= bridge`）。

## 二、外壳加了**去重闸门**（注入不删，只让位）

`src/main.js` 的 `injectLocalUi()` 现在先查本机 profile：**装了插件的那条就不再注入**，
并写一行 `shell.log`。判据只看本机磁盘（`PI.listInstalled`，纯本地扫描，不联网）。

⇒ 干净装机 / 没勾选插件的用户，功能仍由**注入兜底**；装了插件的就是插件在跑。
两者共用同一段 DOM 逻辑与同一个调试钩子，靠 `stats.src` / `__dshSidebarOpen.src`
（`"inject"` / `"plugin"`）区分身份 —— **验收脚本据此断言"现在跑的是哪一个"**。

## 五、这一版同时带来的认定与边界（诚实写清楚）

- **宿主不校验路径是否存在**（实测）：拿不存在的路径问 `session.openWorkspacePath`，它照样回
  `ok:true`（契约只是"把路径交给本机打开器"）。⇒ 插件版**收不到"文件不存在"这种失败**，
  注入版当年靠外壳的 `shell.openPath` 能拿到错误串。表现差异：注入版会弹红色 toast，插件版不会。
- **"宿主是否拒绝工作区之外的绝对路径"未经实测** —— 记为**未知 / 需复核**（不敢拿真实路径去试，
  那会真的启动程序）。
- 两个插件的 `dsh.client` 声明：`model-search` **不声明任何模块依赖**（纯 DOM，最大化可移植性）；
  `sidebar-open` 声明 `@deepseek-ai/dsh-api-remotes` + `@deepseek-ai/dsh-api-session-controller`
  （与官方 `dsh-client-ui-open-in-app` 同一批），cordis 侧 inject `["remote","remote.session"]`。
