# DSH 集成桌面端 0.2.4

把官方 DeepSeek Harness 内核装进原生 Electron 外壳。**外壳不修改内核的任何文件**，
内核由外部独立安装与升级 —— 升级内核不需要动外壳。

> 这一版有两件事：**页面切换器**（浏览器式的三页切换）+ **能自己检查更新**。
> 0.2.3 只提交了代码、没出包，所以这里把它一并写上。

## 一、三页切换：本机 DSH / DeepSeek 网页版 / DeepSeek 开放平台

窗口**右侧边缘**有一条细把手（默认 20px，悬停展开），点一下弹出清单，点哪页切哪页，
当前页打 ✓。

| 页面 | 是什么 |
|---|---|
| **本机 DSH** | 就是这个客户端本身（本机内核的官方界面） |
| **DeepSeek 网页版** | <https://chat.deepseek.com/> |
| **DeepSeek 开放平台** | <https://platform.deepseek.com/> |

**三个入口**：右侧把手（主入口）/ **托盘右键 → 页面**（带勾选）/ **Ctrl+1 / 2 / 3**。

几个刻意的取舍：

- **切走不停机** —— 网站是以**一层独立视图**盖在窗口上的，本机界面在下面继续活着，
  内核不断线、会话照常跑（看一眼网页不会打断长回答）。
- **切回不重载** —— 站点页面只隐藏、**不销毁** ⇒ 不丢滚动位置、不丢登录态。
- **网站页面里也有这个把手** —— 否则进去之后就没有出口了。
- **登录态存在应用自己的数据目录里**，登录一次就记住。

## 二、外壳设置终于能随手打开了

以前只有**加载页底部**和托盘右键能找到外壳设置 —— 已经进到界面里就没法改了。
现在**切换面板的最后一栏**就是「⚙ 外壳设置…」，本机页面与两个网站页里都点得到。
（托盘「设置…」与 `Ctrl+,` 仍然在，是备选入口。）

## 三、设置里多了「检查更新」—— 不用再手动装

外壳设置里新增**更新**一栏：

1. 点「检查更新」→ 去本项目的 GitHub Releases 查新版本；
2. 有新版本就显示版本号、安装包大小、以及**这一版改了什么**；
3. 点「下载并安装」→ 下载到临时目录（带进度条）→ 启动安装器 → 外壳退出，
   安装器装完会**自己把新版本打开**。

托盘右键也加了一条「检查更新…」，点它直接打开设置页并跳到更新栏。

**边界（说清楚，别以为它比实际更安全）**：

- **不校验签名**：只保证「从我们自己的 GitHub 仓库、经 HTTPS 下载」。
- **不静默安装**：必须你点「下载并安装」才动，安装器是**你可见地**启动的。
- **不后台轮询**：只有你点的时候才查一次。
- **只认自己下载的那个文件**：安装那一步只接受本应用临时目录里的安装包，
  不接受任意路径 —— 否则"检查更新"就变成了一个"运行任意 exe"的通道。
- 网络走 **Electron 自带的网络栈**（不是 node 的 http）⇒ **自动走系统代理**。

## 四、验证方式（真跑，不看自述）

```
node scripts/ui-check.js pages      # 三页切换：真点把手、真切页、真回读主进程状态（15 项断言）
npm run update:check                # 检查更新链路：真连一次 GitHub Releases（只读）
npm run provision:check             # 内置插件落位（63 项断言）
```

`update:check` 是本版新增的探针，它**只发一次 GET、什么都不写**，并且会：
① 真去查一次 Releases；② 打印挑中的安装包名字与大小；③ 当场验一遍**版本比较这把尺子**
（含 `0.2.10 > 0.2.9`、`0.2.4-rc.1 < 0.2.4` 这两条容易写错的）。
★ 它还会提醒你：用 `electron 脚本.js` 直接跑时 `app.getVersion()` 拿到的是 **Electron 的版本**，
别被那个数字骗了。

## 五、安装须知

1. **先退出正在运行的旧版本**（托盘右键 → 退出；点右上角 X 只是最小化到托盘）。
   本应用是单实例的，旧版还开着的时候启动新版会**直接退出并聚焦旧窗口**，看起来像"双击没反应"。
2. 装完如果桌面图标还是旧的，那是 **Windows 图标缓存**，不是没装上：
   `ie4uinit.exe -show`，或重启一次资源管理器。
3. **需要本机已安装官方内核**：`npm i -g @deepseek-ai/dsh`
   （本版**没有**把内核打进去 —— 那样安装包要从 90 MB 涨到 250 MB 上下，
   而需要这个客户端的人本来就有 Node）。
4. **插件不用单独装** —— 打开客户端就有（0.2.2 起内置）。
