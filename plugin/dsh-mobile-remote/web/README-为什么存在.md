# ⚠️ 这个目录是**过渡期的兼容副本**，别删（手机页 404 的原因就在这）

## 它为什么存在

2026-09-21 本插件按"电脑侧 / 手机侧"分了层：

```
desktop\   = 电脑侧（宿主半边 index.js + 电脑端界面 client.js + 二维码库 qr.cjs）
phone\     = 手机侧（网页）★ 真源在这里
web\       = 本目录 —— phone\ 的逐字节副本
```

**但宿主半边（`desktop/index.js`）是在内核启动时加载进内存的**。
本机**正在运行**的那个内核启动于分层之前，它内存里的 `WEB_DIR` 还指向 `web\`。
把 `web\` 删掉 ⇒ **手机页当场 404**（2026-09-21 实测：`/styles.css` 返回 404，
手机上就是白屏）。

所以这里放了 `phone\` 的副本，让**旧版宿主**继续能发页面。

## 什么时候能删

**重启一次客户端之后**。重启后内核加载的是新版 `desktop/index.js`，
它的 `PHONE_DIR` 指向 `phone\`，不再读 `web\` ⇒ 本目录即可删除。

判据（重启后跑一次，`/state` 里能看到新字段就说明新版已生效）：

```powershell
node D:\deepseek-workspace\5.DSH集成桌面端\scripts\mobile-remote-status.js
```

（退出码 0 = 新版在跑，此时删 `web\` 安全。）

## 别往这里改东西

**改样式/改脚本请去 `phone\`**。这里是副本，改它不会长久 ——
下次同步时会被 `phone\` 的内容覆盖（见 `_sync` 说明，如尚未同步则手动复制）。
