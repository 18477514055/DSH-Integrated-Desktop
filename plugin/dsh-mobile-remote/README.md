# dsh-int-mobile-remote

用手机遥控电脑上的 DSH：电脑端显示一个二维码，手机扫码后在**局域网**里查看会话、看流式输出、发消息、中断。

*Scan a QR code on the desktop and drive this DSH from your phone over LAN.*

---

## 它做什么

电脑端出一个**二维码**，手机扫码即连 —— **不用云、不用账号、不出局域网**。

连上之后，手机上可以：

- 看**会话列表**并切换
- 看**流式输出**（边生成边看，和电脑上一样）
- **发消息**
- **中断**正在跑的生成
- 把**工具调用与思考过程**折叠起来看（不是铺一屏）
- 浅色 / 深色主题跟着走

手机端界面是**按真机逻辑尺寸**做的（默认 375×834 dp 那一档），不是把桌面布局缩小。

## 怎么用

1. 电脑端打开插件的入口，屏幕上出现二维码。
2. 手机连**同一个 Wi-Fi**，扫码。
3. 手机上就能看和发。

## 安装

```bash
dsh plugin --profile web add dsh-int-mobile-remote
```

装完**重启一次**客户端 / 内核生效。

## 边界（如实说）

- **只走局域网**：手机和电脑必须在同一个网段；人在外面用不了。
- 电脑端的 DSH 必须开着 —— 关掉客户端就没有可遥控的对象了。
- 同一个 Wi-Fi 下连不上时，先排除「电脑连了手机热点」这类**跨网段**情况。
- 在 Windows 上开发与验证；其他平台未验证。
