# dsh-multi-session

一次把**多条提示词**发进**多个新会话**：一个大弹窗里放多个输入框，一键同时开工。

*Compose N prompts and launch N sessions in one click.*

---

## 它做什么

- 一个弹窗里放**多个输入框**，每行一条提示词。
- **一键**把这 N 条分别发进 N 个**新会话**（不是排队塞进同一个会话）。
- 每一行都可以带**附件**、并**指定用哪个模型** —— 也就是「这一条用什么、带什么」都能逐行定。
- 输入时可以用 `/` 菜单插入提示词、用 `@` 菜单插入文件与目录。

## 为什么需要它

「同一个问题问几个模型」、或者「一件事拆成几路并行做」时，官方界面只能一个个新建会话、反复粘贴。
这里一次写完、一次发出去。

## 安装

```bash
dsh plugin --profile web add dsh-int-multi-session
```

装完**重启一次**客户端 / 内核生效。

## 边界（如实说）

- 它只负责**把消息发出去**；发完之后每个会话就是普通会话，各自独立跑。
- 每行是「提示词 + 附件 + 模型」，不含权限预设 / Agent 预设 / Plan 模式。
- 一次开太多会话会同时占资源 —— 数量你自己看着办。
