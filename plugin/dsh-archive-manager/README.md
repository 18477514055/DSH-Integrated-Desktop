# dsh-int-archive-manager

在 DSH 右侧边栏新增一个「已归档」分组：把已经归档的对话集中列出来，**能搜、能筛、能真正删掉腾空间**。

*An "Archived" group in the DSH sidebar: list, search, filter and permanently remove archived conversations.*

---

## 它做什么

- **集中列出**所有已归档的对话（官方界面里归档之后就很难再找回来）。
- **搜索**：按标题、按目录名。
- **按天筛选**：只看某一天的归档。
- **永久删除**：把选中的归档送走，用来腾出空间，并要求**二次确认**。

## 三个行为，说清楚

| 行为 | 具体做了什么 |
|---|---|
| 「永久删除」 | 文件被**移到系统回收站**，不是不可恢复的销毁 —— 后悔了还能捞回来 |
| 转储文件夹 | 由**你在界面里指定**，随时可改 |
| 真正的销毁 | 什么时候清空回收站、什么时候彻底删，**由你自己决定** —— 插件不替你按那个按钮 |

## 为什么需要它

官方界面只提供「归档」这个动作。归档之后想在几百个对话里找出某一个，基本只能翻列表。
侧边栏的「已归档」分组把「找回来」和「清掉」这两件事变成一次点击。

## 安装

```bash
dsh plugin --profile web add dsh-int-archive-manager
```

装完**重启一次**客户端 / 内核生效。

## 边界（如实说）

- 只处理**已归档**的会话，不动你正在用的会话。
- 「永久删除」走系统回收站 ⇒ 最终结果取决于你的回收站设置。
- 在 Windows 上开发与验证；其他平台未验证。
